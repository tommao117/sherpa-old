## 开发约定

- 一批工作明确所属模块、阻塞依据、最小改动、验收与停止条件。
- 实现、离线验证、真实局部验证和完整任务通过分别记录。
- 局部任务及证据更新到模块计划，总览只更新依赖和阶段状态。
- 当前保持小模型日常决策，先依据 trace 改进工具和流程；全面切换强模型需重新讨论。
- 沿既定路线持续开发到可集成测试的停点，不按单个辅助函数反复请求确认；随后用真实任务验证并迭代。改变目标、行为要求、权限、GPU 执行或费用范围，以及缺少验收标准时停止确认。
- 每完成一个相对完整阶段，验证通过并检查暂存差异后提交代码及相关测试、文档；提交说明明确阶段范围，不混入本地环境、凭据或生成数据。
- 保留用户修改、历史 trace 和 `.codebuddy/` 项目数据；未经明确要求不推送或启动常驻任务。
